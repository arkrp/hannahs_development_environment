This folder should container five keys with the exact specified names:

Keys which are important:

admin_key.pub
   The ssh public key corresponding to the device which you will be using to access the development environment.
dev_key
   The ssh key which verifies the dev (priveleged account)'s identity
dev_key.pub
   The corresponding public key for dev_private_key. Distribute this to grant the dev container access! (for sshfs or other)

Keys which must exist but are not that important

sandbox_key
   The ssh key which verifies the sandbox (isolated unpriveleged)'s identity
sandbox_key.pub
   The corresponding public key to sandbox_private_key.
dev_host_key
   key to prove identity as the dev_container ssh host.
dev_host_key.pub
   key that denotes the identity of the dev_container ssh host.
sandbox_host_key
   key to prove identity as the sandbox_container ssh host.
sandbox_host_key.pub
   key that denotes the identity of the sandbox_container ssh host.
